format_list_bulletedAvailable streams

Lists the releases in a title's Version menu (resolution, size, seeds, source), like Elementum. "Auto" stays the default and your pick is remembered. Reopen the page if the list isn't there yet.

auto_awesomeWhat Auto picks

Tried first. If there's none, the closest lower resolution, then higher.
Well-seeded releases under about 15 GB (4K) or 8 GB (1080p) are tried before huge remuxes, which start slowly (episodes: 6 GB and 3 GB). The big ones stay in the Version menu.
A 4K release with fewer seeders is tried after the best 1080p one: a small swarm can't download 4K fast enough to start quickly. It stays in the Version menu.
Suggested: 50. Lower it (20-30) if your connection is fast and 4K starts well; raise it if 4K still starts slowly or stutters.
If a release won't start (no peers send its file list in time), the next best is tried, up to this many.

boltFaster start

Fetches the start and end of Auto's release (about 6 MB) so play starts much sooner. Leave the page and it stops after a minute.
Two minutes into an episode, quietly fetches the start of the next one (about 40 MB, then it pauses), so Next or autoplay starts almost at once.
Reads the video, audio and subtitle tracks of the top releases so they show in the Version menu. Uses some bandwidth per title page.
Many releases include separate subtitle files (.srt and the like). They're added to the subtitle menu, labelled by language. Unlike subtitles inside the video, they don't need the whole release downloaded first.

devicesPer-device limits

Caps what Auto plays on a device, e.g. a TV that can't handle 4K. "Device" matches the device's name, its name in Dashboard > Devices, or the app. Picking a version in the Version menu always plays that version.

timerTorrent lifetime

When full, the least recently used torrent is removed.
A torrent stops completely (no uploading, no connections) a minute after nobody is watching it, and starts again when you play it.

folderStorage

A target for the torrents the plugin is running, checked every few minutes: over it, the least recently watched ones nobody is watching are removed. Not a hard cap: a title being watched is never removed, so a large release can go over it, and files kept after playback aren't counted.
Off: files are deleted when a torrent is removed, so the disk doesn't fill up.

playlist_playTrakt

Adds Trakt's trending, popular, anticipated and box office lists to the catalogs, plus your lists and watchlist (Libraries tab). Create a free API app at trakt.tv/oauth/applications (redirect URI: urn:ietf:wg:oauth:2.0:oob) and paste its Client ID.

Connecting your account adds your private watchlist and recommendations.

settings_ethernetStream links

Blank (recommended): each device is given links using the address it reached Jellyfin by, so devices at home use the home address and devices away from home use your reverse proxy's address. Only enter an address to force one for every device, e.g. http://192.168.1.10:8096. Links are updated automatically when you save.
Stream token:
The secret in stream links that lets players stream without a Jellyfin login. Make a new one if a link was shared by mistake; all links are updated straight away. Otherwise the old token keeps working for 10 minutes, so whatever is playing isn't cut off.

New library

Jellyfin needs a folder for a new library, so P2P Stream creates the folder first. You add the library with it in the next step.

  1. Select Save on this page.
  2. In Dashboard > Libraries, add a library with this folder.

Once the library exists, it shows up here under its name.
